# Taklif Pro — Платформа электронных пригласительных

> **Приватный репозиторий. Коммерческий продукт.**

Полноценная SaaS-платформа для создания интерактивных электронных пригласительных (Таклифнома / Шақыру) с RSVP, рассадкой, аналитикой и монетизацией.

## Статус проекта

- **Версия:** Pro (полная)
- **Доступ:** Только приватный репозиторий (GitHub Pro)
- **Цель:** Коммерческий запуск на рынке Казахстана (Шымкент / Сайрам и далее)

## Основные возможности

### Для клиентов
- Вход через Google
- Демо-режим → оплата → полный доступ
- Визуальный конструктор пригласительных
- 6+ премиальных шаблонов
- Персональные ссылки для гостей
- RSVP в реальном времени
- Рассадка по столам
- 3D-конверт и анимации
- Музыка, карта, таймер, wishlist
- Красивые отчёты + экспорт в Excel/PDF
- Telegram-уведомления

### Для администратора
- Полная админ-панель
- Статистика пользователей и платежей
- Управление тарифами и доступами
- Финансовые отчёты

## Технологический стек

- **Frontend:** Next.js 15 + TypeScript + Tailwind CSS + Framer Motion
- **Backend:** Firebase (Auth, Firestore, Storage, Hosting)
- **Оплата:** Kaspi Pay
- **Уведомления:** Telegram Bot API
- **Состояние:** Zustand
- **Хостинг:** Vercel / Firebase Hosting

## Безопасность и доступ

- Репозиторий **строго приватный**
- Секреты (Firebase, Kaspi, Telegram) хранятся только в `.env.local` и GitHub Secrets
- Никогда не коммитить `.env*` файлы
- Доступ только у владельца и доверенных лиц

## Установка (локально)

```bash
git clone git@github.com:YOUR_USERNAME/taklif-pro.git
cd taklif-pro
npm install
cp .env.example .env.local
# Заполнить все ключи
npm run dev
```

## Важные правила

1. Не делать репозиторий публичным
2. Не добавлять посторонних collaborator'ов без необходимости
3. Все ключи — только через Environment Variables
4. Перед каждым пушем проверять, что секреты не попали в код
